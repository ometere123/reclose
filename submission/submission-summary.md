# Reclose — submission summary

**Runtime assurance for autonomous protocols.** Reclose combines GenLayer semantic judgment with deterministic policy enforcement so an autonomous protocol can respond to governed evidence without granting a Reporter, monitor or model arbitrary emergency authority.

R1 includes GenLayer contracts, an SDK, policy compiler, evidence builder, transaction tracker, CLI, Sentinel candidate tooling and a frontend now wired for live-by-default canonical reads and a Transaction Kit wallet review. The old `accepted` failure is superseded by a successful isolated typed-address `decided` simulation (read-only; no transaction submitted). The active policy's immutable Kernel/Judge generation predates the `decided` fix, so browser signing is fail-closed until source-matched contracts and policy are verified. The full incident/recovery lifecycle, E1 Run A/B, H1 and final live fee coverage are not complete. See `known-limitations.md`; do not claim live containment or recovery.
