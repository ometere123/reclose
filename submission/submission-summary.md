# Reclose — submission summary

**Runtime assurance for autonomous protocols.** Reclose combines GenLayer semantic judgment with deterministic policy enforcement so an autonomous protocol can respond to governed evidence without granting a Reporter, monitor or model arbitrary emergency authority.

R1 includes GenLayer contracts, an SDK, policy compiler, evidence builder, transaction tracker, CLI, Sentinel candidate tooling and an operational frontend. The current Studio-dev deployment has an active policy and verified on-chain bindings. The canonical incident lifecycle is not yet live-proven: Studio-dev's accepted-message simulation fails in a minimal explicit-allocation reproduction, so Run A stopped before incident submission. Run B and H1 are not complete. See `known-limitations.md` and the repository evidence links before making live-containment claims.
