# Benchmark highlights

The R1 corpus contains 78 threat-mapped scenarios. The repository integrity check confirms corpus shape and mapping; it does not execute the full H1 campaign. Full precision, recall, false-intervention, critical false-negative, `UNDETERMINED`, validator-disagreement, latency, fee, recovery and post-state metrics are not yet available. The isolated typed-address `decided` simulation passed, but Run A requires a source-matched deployment; Run A/B and H1 remain incomplete. No blocked or not-run scenario is counted as a pass.
