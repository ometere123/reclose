# Benchmark highlights

The R1 corpus contains 78 threat-mapped scenarios. The repository integrity check confirms corpus shape and mapping; it does not execute the full H1 campaign. Full precision, recall, false-intervention, critical false-negative, `UNDETERMINED`, validator-disagreement, latency, fee, recovery and post-state metrics are not yet available. E1 Run A is blocked before incident submission by the reproduced Studio-dev accepted-message simulation limitation. Run B and H1 remain not run. No blocked or not-run scenario is counted as a pass.
